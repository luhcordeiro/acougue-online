# Migrações MySQL (histórico)

Estas migrações eram do MySQL/TiDB, antes da migração para Cloudflare D1 (SQLite).
Ficam aqui só como registro do histórico do schema — **não são aplicadas por nada**.

As migrações válidas estão em `drizzle/migrations/`, geradas com dialeto SQLite e
aplicadas pelo `wrangler d1 migrations apply`.
